# SG Taekwon-Do Website
Static responsive website for SG Taekwon-Do, designed to visually mirror the SGTKD-SCIO website while using the SG Taekwon-Do tartan and club logo.

## Pages
- Home
- About
- Classes
  - Adults
  - Juniors
  - Ninja's
- Blog / News
- Partners
- Contact Us

## Deploy
Upload the contents of this folder to a GitHub repository and connect it to Cloudflare Pages or GitHub Pages.

## Easy updates
- Class timetable: `classes.html`
- Contact details: `contact.html`
- News articles: `news.html`
- Branding/background: `styles.css` and `assets/`
